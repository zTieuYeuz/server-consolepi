# Tu dien ten goi (tieng Viet khong dau)

Ma nguon dat ten bang tieng Viet khong dau (da chon giu nguyen, khong doi sang tieng Anh). Bang tra nhanh:

| Tu | Nghia | Vi du |
|---|---|---|
| ban / ban_phat_hanh | mot phien ban cai | `releases/2.0.1`, `PH.kiem_ban` |
| goi | file cap nhat `.cspkg` hoac goi sao luu | `goi.dong_goi`, `saoluu.kiem_goi` |
| kho | (1) kho trung tam (may chu .34) (2) lop luu du lieu `Kho*` | `khotrungtam`, `KhoJson` |
| may | may tram / may Pi / may Windows duoc quan ly | `uem_*`, `may.json` |
| khoa | khoa mat ma (khong phai "lock"); `khoa_lenh` = lenh khoa may | `khoa.py`, `khoa_lenh.py` |
| tin cay | tai lieu tin cay (danh sach khoa duoc phep, do khoa goc ky) | `tin-cay.json` |
| danh muc | danh sach ban co san tren kho (da ky, het han ngan) | `danhmuc.py` |
| dichuyen | migration du lieu | `core/dichuyen.py` |
| saoluu / khoiphuc | backup / restore | `saoluu.py` |
| nang cap / ha cap | upgrade / downgrade | `nangcap.py` |
| hoan tac | rollback | `hoan_tac` |
| suc khoe | health check | `_b_suc_khoe` |
| nguyen ven | integrity (bang bam khop) | `nguyenven.py` |
| chan / canh bao | khong cho lam / chi canh bao | `kiem_dieu_kien_*` |
| thu muc / duong / tep | thu muc / duong dan / file | `thu_muc`, `duong`, `tep` |
| lenh | lenh he thong (tien trinh con) | `core/lenh.chay` |
| nhatky | log | `core/nhatky` |
| bo qua (loi) | nuot loi co chu y nhung de lai dau vet | `nhatky.bo_qua` |
| ket | ket qua (`Ket`) | `lenh.Ket` |
| bo cuc | layout thu muc du lieu (cu / moi) | `BO_CUC_MOI` |
| cau noi | module alias cu -> moi | `ui/*.py` |
| hop dong | file chuan de so sanh truoc/sau khi sua | `tests/hop-dong` |
| golden | dau ra mau phai khop tung byte | `tests/golden` |
