# Bộ 100 script mẫu cho kho Console System

Script Windows (`.ps1`) chạy trên máy vừa cài xong, chọn ở bước "Script" của kịch bản. Hành vi cố định, không tham số,
chạy lại nhiều lần không hỏng, ghi log `C:\ConsolePi\logs`, mã thoát 0 = thành công.

- `ps1/` - 100 file đã đưa lên kho (sinh bằng `build_all.py` từ `def_a.py`, `def_b.py`, `def_c.py`).
- `mota_kho_moi.py` - tên và mô tả (nói script làm được gì) tiếng Việt hiện trên kho.
- Thử thật: `iso/test/thu-script-kho.sh` (máy mẫu Windows 10, 2 lượt + khởi động lại + kiểm hồ sơ Default User).
- Đã thử 12-13/10/2026 trên Windows 10 Pro 22H2 (máy ảo). Chưa thử Windows 11 và máy thật.
